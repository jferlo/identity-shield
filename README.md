# Identity Shield · GitHub Pages

Juego educativo para la asignatura Fundamentos de la Seguridad de los Sistemas Informáticos y de la Información.

## Publicación rápida

1. Cree un repositorio público en GitHub.
2. Suba `index.html` y `.nojekyll` a la raíz del repositorio.
3. Vaya a Settings > Pages.
4. En Build and deployment seleccione `Deploy from a branch`.
5. Seleccione la rama `main` y la carpeta `/(root)`.
6. Guarde y espere a que GitHub muestre la URL publicada.

## Canvas

Cuando tenga la URL de GitHub Pages, reemplace `URL_DEL_JUEGO` en `canvas_iframe.txt` y pegue el código en el editor HTML de una Página de Canvas.

## Nota sobre el ranking

El ranking se guarda en el navegador del estudiante mediante `localStorage`. Registra las finalizaciones realizadas en ese mismo navegador/perfil.
